# OS

Учебная операционная система, созданная в рамках курса системного программирования
под руководством **Бахмацкого Владислава Игоревича**.

## О проекте

Цель проекта — обучить студентов системному программированию на практике: в рамках курса
мы с нуля разрабатываем операционную систему и тулчейн вокруг неё — ядро, драйверы,
файловую систему, мини-libc, пользовательские программы и графический интерфейс.
Особенность курса — синергия с ИИ: значительная часть кода пишется совместно с ИИ-агентами.

## Запуск

Для запуска используется эмулятор **QEMU**:

```bash
qemu-system-x86_64 -hdd hdd.img
```

Подробности о сборке и запуске — в [TOOLCHAIN.md](TOOLCHAIN.md),
архитектура системы — в [ARCHITECTURE.md](ARCHITECTURE.md).
